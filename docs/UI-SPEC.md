# AVDDesktop UI 设计规范

> 视觉基线来自 `assets/` 下的参考截图（MuMu 模拟器设备管理页）：**浅色、留白充足、圆角卡片、蓝色主操作、轻量分割线、图标 + 小字导航**。
> 本文所有数值都是落地值，前端直接对应 `frontend/src/styles/tokens.css` 中的 CSS 变量。

---

## 1. 设计原则

1. **状态优先**：用户打开软件第一个问题是"我缺什么、能不能跑"。首页用**状态卡片**而不是表格回答，每张卡片自带修复入口。
2. **一步一动作**：每张卡片/每个空状态都只给一个主 CTA（蓝色实心），次操作降级为文字按钮。
3. **长任务可见但可离开**：所有耗时操作进入顶部进度条 + 底部任务抽屉，弹窗关掉任务继续跑。
4. **不吓人**：命令、路径、日志默认折叠；展示给用户的是中文短语 + 版本号 + 大小。
5. **一致性**：所有"设备"相关视觉用卡片（图片 + 标题 + chips + 圆形操作按钮），与参考图对齐。

│ [首页] │  卡片 / 列表 / 表格                                                   │
│ [设备] │                                                                     │

| 区域 | 尺寸 | 说明 |
| --- | --- | --- |
| ① 标题栏 | 高 56 px；左右 padding 16/12 px | 左：应用图标（20×20 圆角 5px，主色底）+ 标题 15px/600；右：任务指示器（有运行中任务时旋转图标 + 数量徽标）、汉堡菜单、分隔线、最小化/最大化/关闭 36×36 热区 |
| ② 导航栏 | 宽 80 px；白底；右边框 1px `--border-subtle` | 项：56×56 圆角 10px，图标 22px + 标签 11px，间距 4px；激活项背景 `--bg-hover`、文字/图标 `--text-primary` + 600；非激活 `--text-tertiary` |
| ③ 页面头部 | 高 64 px；左右 padding 24 px | 标题 20px/600 + 副标题 13px `--text-tertiary`；右侧主 CTA |

| ⑤ 任务抽屉 | 折叠 40 px / 展开 200 px | 白底，上边框 1px，左侧"任务 (N)"，右侧展开/收起、全部取消 |

**窗口**：默认 1180×760，最小 960×640（`MinWidth/MinHeight`）；`Frameless: true` + `BackgroundColour: #F5F6F8`。

## 4. 组件规范

### 4.1 按钮

| 类型 | 样式 | 尺寸 |
| --- | --- | --- |
| Primary | 蓝底白字，圆角 8，前置 16px 图标（如 `+`） | 高 36，padding 0 16；大号（页面主 CTA）高 40 |
| Secondary | 白底、1px `--border`、`--text-primary`、前置 16px 图标 | 高 36 |
| Text/Ghost | 无底色，`--text-secondary`，hover 变 `--bg-hover` | 高 32 |
| Icon | 36×36，圆角 8；hover `--bg-hover` | 36 |
| Circle | 48–52 直径、圆角 full（参考图的圆形播放按钮：深色 `#1D2129` 底 + 白色三角；停止态用 `--primary` 底 + 白色方块） | 48 |
| Danger | `--danger` 底白字 或 白底红字红边（用于删除确认） | 36 |

### 4.2 Chip / 标签（参考图的 `Android 12` `4 核` `6 GB`）

- 高 24 px，padding 0 8，圆角 6，背景 `--bg-hover`，文字 13px `--text-secondary`
- 语义变体：`--success-soft`/`--success`（运行中）、`--warning-soft`（启动中）、`--neutral-soft`（已停止）、`--danger-soft`（错误）
- 图标chip（如"Google Play"）在文字前放 12px 图标

### 4.3 卡片

```
┌───────────────────────────────────────────────────────────────┐
│  [缩略图 168×96 圆角12]   设备名（22px/600）        [▶圆形][…]  │
│                           [chip][chip][chip]                  │
│                           1080 × 2400  |  420 DPI   ● 已停止   │
└───────────────────────────────────────────────────────────────┘
```

- 白底，圆角 12，1px `--border-subtle`，`--shadow-card`；hover 抬升 `--shadow-pop` + 边框 `--primary-border`
- 运行中卡片：缩略图右上角状态圆点（`--success` 呼吸动画）+ 底部一行"emulator-5554 · 端口 5554"
- 缩略图来源：优先 `adb exec-out screencap` 实时截图（≤2s 刷新，仅运行中），否则用系统镜像主题色渐变占位 + 首字母
- 右下角操作：`…` 打开菜单（编辑 / 克隆 / 重命名 / 快照 / 清除数据 / 打开目录 / 复制启动命令 / 删除）

### 4.4 工具类

| 组件 | 规格 |
| --- | --- |
| 搜索框 | 高 36，无边框，圆角 8，左侧 18px 放大镜，右侧 `⌘K` 提示；聚焦时背景 `--bg-hover` |
| 分段控件（参考图右侧网格/列表切换） | 容器背景 `--bg-hover`，圆角 8，padding 2；选中项白底 + 1px 边框 + `--shadow-card`；项 32×28 |
| 下拉选择 | 高 36，白底 1px 边框；展开面板圆角 8 + `--shadow-pop`；支持搜索（设备档案 90+ 项必须可搜） |
| 表单行 | 左侧 label 14px `--text-secondary` 宽 140；右侧控件；行高 44；错误态：控件红色描边 + 12px 红色说明 |
| 开关 | 宽 36 高 20，圆形滑块；开启 `--primary` |
| 数字/滑块（内存、核数） | 滑块 + 右侧数值 chip（含单位），有 min/max 时显示刻度提示 |
| 进度条 | 高 6，圆角 full，轨道 `--bg-pressed`，填充 `--primary`；不确定态用条纹动画 |
| 步骤条（向导/一键准备） | 横向，节点 24px 圆形；完成 `--primary` 实心对勾、当前 `--primary` 描边、未来 `--text-disabled`；连接线 2px |
| 表格 | 表头 12px `--text-tertiary` 背景 `--bg-subtle`；行高 44；斑马纹不用；hover `--bg-subtle`；数字右对齐 tabular-nums |
| 弹窗 | 圆角 16，`--shadow-modal`，遮罩 `rgba(29,33,41,.45)`；头部 56（标题 16/600 + 关闭）+ 内容（padding 24）+ 底部 64（右侧按钮组）；宽 `sm 480 / md 640 / lg 880 / xl 1040` |
| Toast | 右上角，宽 320，圆角 12，图标 + 标题 14/600 + 描述 13；4s 自动消失 |
| 空状态 | 居中，80px 线性插画/图标（`--text-disabled`）+ 标题 16/600 + 说明 13 + 一个主 CTA |
| 骨架屏 | 卡片与列表统一骨架，`--bg-hover` 微光动画 1.2s |
| 日志控制台 | 等宽 12px，深色底 `#1B1D21`（浅色主题下也保持深底），行号可选，高亮 `error/warn/info`，支持复制全部、自动滚动开关、关键字过滤 |

- 底部主按钮"使用该源"写回 `activeSourceId`

### 5.4 创建 / 编辑设备向导（DeviceWizard）

四步，`lg` 弹窗（880px），左侧步骤条 + 右侧表单，底部 上一步/下一步/创建。

**Step 1 基础信息**

| 字段 | 控件 | 校验 |
| --- | --- | --- |
| 名称 | 输入框 | `^[A-Za-z0-9._-]{1,64}$`，非空、不与已有 AVD 冲突（实时校验 + 提示可用名） |
| 显示名称 | 输入框 | 允许中文/空格，默认 = 名称 |
| 分组 / 标签 | 输入框 | 可选，用于列表筛选 |
| 备注 | 多行 | 可选 |

**Step 2 设备型号（profile）**

- 顶部搜索 + 分类 Tab（手机 / 平板 / 桌面 / 电视 / 车机 / 穿戴 / XR / 其他），源自 `avdmanager list device`
- 列表项：名称 + OEM + 标签 +（若有）分辨率/密度；右侧小预览（按尺寸比例画的矩形）
- 选中后右侧显示"该档案提供的默认配置"，并提示是否被 Step 4 覆盖

**Step 3 系统镜像**

- 已安装镜像（按 API 倒序，chip 显示 tag / ABI / 是否 Google Play）
- 未安装但可用 → 从当前镜像源拉取列表，显示大小、下载按钮（走安装 Job，可后台）
- 冲突提示：Play 镜像不支持 `adb root`；ARM 镜像在 x86 上会慢

**Step 4 硬件与高级配置**（分组折叠，默认展开「计算资源」）

| 分组 | 字段（`config.ini` 键） |
| --- | --- |
| 计算资源 | RAM `hw.ramSize`（MB，默认来自档案）、核心数 `hw.cpu.ncore`、VM Heap `vm.heapSize`、GPU 模式 `hw.gpu.mode`、启用 GPU `hw.gpu.enabled`、CPU 架构 `hw.cpu.arch` |
| 存储 | 内部存储 `disk.dataPartition.size`（GB 滑块，默认 6）、缓存分区 `disk.cachePartition` + 大小、SD 卡 `hw.sdCard` + `sdcard.size` |
| 显示 | 分辨率 `hw.lcd.width`/`hw.lcd.height`（含预设：1080×2400、1440×3120、1280×720、2560×1600…）、密度 `hw.lcd.density`、初始方向 `hw.initialOrientation`、显示设备边框 `showDeviceFrame`、动态皮肤 `skin.dynamic` |
| 输入 | 硬件键盘 `hw.keyboard`、D-Pad `hw.dPad`、实体按键 `hw.mainKeys`、多点触控 `hw.multitouch` |
| 传感器 | 加速度/陀螺/接近/光/磁力/方向/压力/温度/心率（布尔开关组） |
| 相机 | 后置 `hw.camera.back`、前置 `hw.camera.front`（none / emulated / virtualscene / webcam0） |
| 网络 | 网络速度 `runtime.network.speed`、网络延迟 `runtime.network.latency`、DNS `hw.dns1`、HTTP 代理 `hw.httpProxy` |
| 启动行为 | 冷启动 `fastboot.forceColdBoot`、快照启动 `fastboot.forceFastBoot`、启动参数预设（冷启动 / 快速启动 / 无窗口 / 可写系统分区 / 无动画）、自定义参数（原样追加，前后白名单校验）、时区 |

- 底部固定"查看等效命令"文字按钮 → 打开只读代码块（`avdmanager create avd …` + `emulator -avd …`）
- 提供"直接编辑 config.ini"开关 → 切换为等宽文本域，保存时做语法与键名校验并给出 diff（新增/修改/删除三类高亮）

### 5.5 SDK 管理页

- 左：分类树（命令行工具 / 平台工具 / 模拟器 / 系统镜像 / 平台 / 构建工具 / 驱动与扩展）
- 右上：Tab（已安装 / 可更新 / 全部）+ 搜索 + 更新频道选择（stable/beta/canary）
- 表格列：勾选、名称（含路径等宽小字）、版本、大小、状态 chip、操作（安装/更新/卸载/校验）
- 底部操作条：已选 N 项 · 合计 X GB → `[安装选中]`
- 安装前 `PlanInstall` 弹窗：依赖列表、总大小、需接受的许可（可滚动阅读文本）+ "同时回退官方源"开关

### 5.6 设置页

分区块：环境（SDK 根 / JDK / AVD 目录 / 环境变量注入）、镜像与下载（活动源、自定义源、并发、限速、代理、临时目录）、许可（已接受列表 + 重新审阅）、默认值（记忆上次向导配置）、外观（主题/语言/视图模式）、高级（日志级别、保留天数、清理缓存、导出诊断包）。

- 加速：当前类型 + 原始输出 + 分步引导（含"需要重启"标记）+ AEHD 安装按钮（触发 UAC，需二次确认）

## 7. 无障碍与可用性

- 所有可点击元素有 `:focus-visible` 主色描边 2px + 2px offset
- 状态不只用颜色：图标 + 文字（`✓ 就绪 / ✕ 缺失 / ! 需修复 / ● 运行中`）
- 弹窗焦点陷阱 + `Esc` 关闭 + `aria-modal`
- 对比度：正文 ≥ 4.5:1，次要文本 ≥ 3:1（`#86909C` 仅用于 ≥ 13px 次要信息，不用作正文）
- 窗口缩放：内容区最小可用宽度 880；卡片网格自适应
